# CFD

CFD results are organized by Reynolds number.

- `RE100/`
  - `CASE/` — CFD setup files
  - `VTK/` — selected VTK exports
  - `VTK_GIF/` — animations generated from VTK/field data
- `RE3900/`
  - `CASE/`
  - `VTK/`
  - `VTK_GIF/`

Keep very large raw transient CFD fields and full time-step VTK datasets outside GitHub. Store only selected or processed outputs here.
